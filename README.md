# 🎵 Player

Музыкальный плеер на React + Tailwind CSS.

## 🚀 Деплой на GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите файлы `index.html`, `styles.css`, `README.md`.
3. Перейдите в **Settings → Pages**.
4. В разделе **Branch** выберите `main` и папку `/ (root)`.
5. Нажмите **Save**.
6. Через пару минут плеер будет доступен по адресу:
   `https://rd7.github.io/natrixnatrix/`
